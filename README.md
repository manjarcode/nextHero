# nextHero

Proyecto de aprendizaje para subir de nivel en Next.js (App Router) y convertirme en referente/early adopter dentro de InfoJobs. Además prepararemos una [formación/README.md](formación) de NextJS para el resto de compañeros.

## Estado actual

- **Nivel de partida:** 4,5 / 10 — básico-intermedio. Ver diagnóstico completo en [assessment/diagnostico-inicial.md](assessment/diagnostico-inicial.md).
- **Fecha del test inicial:** 2026-10-14.
- **Metodología del test:** descrita en [assessment/metodologia-test.md](assessment/metodologia-test.md).

## Objetivo

Pasar de usuario básico (sin uso diario de Next.js) a referente interno capaz de:
- Dominar el modelo App Router (Server/Client Components, Server Actions, caching, streaming).
- Entender y poder explicar features recientes/experimentales (PPR) para posicionarme como early adopter.
- Aplicar middleware y revalidación de caché en escenarios reales.

## Objetivo del ciclo actual (2 semanas)

**Dominar Server Actions** (de 1/10 a 8/10). Ver plan completo en [plan/plan-2-semanas.md](plan/plan-2-semanas.md) y progreso en [plan/skill-matrix.md](plan/skill-matrix.md).

## Estructura del repo

- `assessment/` — diagnóstico de nivel inicial y metodología del test.
- `plan/` — plan incremental por ciclos, skill matrix de seguimiento y [notas incidentales](plan/notas-incidentales.md) (conceptos fuera de foco encontrados en proyectos reales).
- (próximos) `exercises/` — ejercicios prácticos progresivos, uno por hito del plan activo.

## Sesiones de trabajo

En cada sesion de estudio, se hará un pequeño recordatorio de los que se vió en la sesión con una pregunta para ver si han asentado los conocimientos.

Después se procederá a estudiar el tema que corresponda.

Finalmente se hará un wrap-up para hacer resumen de la sesión, donde se documentará que se ha estudiado.

El detalle de cómo ejecutar cada fase (nivel de pistas, qué documentar, cómo acotar la pregunta de cierre) está en [CLAUDE.md](CLAUDE.md), afinado sesión a sesión.
